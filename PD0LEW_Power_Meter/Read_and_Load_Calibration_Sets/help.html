Calibration Tool for Power and SWR Meter

When using old firmware, you can make pictures from the debug screens or write down the values for all calibration sets if needed, to use the values later in your calibration file.

Notice: Notice: There are 8 calibration sets, for Coupler 1 (HF), Coupler 2 (HF), Coupler 1 (6M), Coupler 2 (6M) etc.

Now you can create a text file. This is only needed if you have old firmware.
File name must look like this: PD0LEW_Calibration.txt where PD0LEW is your call.

Before you load new firmware, do a Reset to Default.

Load your new firmware which must be version LJ2000M_6_3.ino.hex or higher.

When loaded, go to the Config Menu and set your call sign.

If you came from an old version, you must adjust the calibration values in the text file (see below). This is for your meter and may look different from your screenshots!
